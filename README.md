# Memory Beat

משחק זיכרון בסטייל "סיימון אמר" (Simon Says): המשחק מנגן רצף צבעים/צלילים שמתארך בכל שלב, והשחקן/ית צריך/ה לחזור עליו בדיוק. טעות בחזרה מסיימת את המשחק.

### חוקי ניקוד

כל שלב שמושלם נכון מזכה בניקוד = 10 נקודות × מספר השלב, כלומר שלבים מתקדמים שווים יותר. הניקוד מוכפל גם לפי רמת הקושי (קל × 1, רגיל × 1.25, קשה × 1.5), וחזרה מהירה על הרצף (לפני זמן סף) מזכה בבונוס מהירות נוסף. ההסבר המלא מוצג לשחקן/ית באמצעות אייקון "?" קבוע מתחת לאייקון טבלת התוצאות.

בנוי כ-HTML/CSS/JavaScript סטטי, בלי framework, בלי bundler ובלי תלויות npm.

## הרצה

אין שרת ואין build. פשוט לפתוח את `index.html` בדפדפן (או להריץ שרת סטטי כלשהו על התיקייה ולפתוח אותה משם).

## מסכים

- **`index.html`** — מסך הלוח, שהוא גם מסך הבית (אין מסך פתיחה נפרד). כולל את לוח ה-4 הפדים, ניקוד, שלב נוכחי, כפתורי PLAY/RESET, ומודל בחירת פרופיל (אווטאר + שם) שנפתח אוטומטית בכניסה ראשונה.
- **`settings.html`** — הפעלה/כיבוי צליל ובחירת רמת קושי (קל / רגיל / קשה).
- **`leaderboard.html`** — טבלת תוצאות: כמה שורות פלייסהולדר קבועות, ולידן שורת השחקן/ית עם השם, האווטאר, השלב והניקוד הגבוה ביותר שנשמרו.

הניווט בין המסכים הוא קישורי `<a href>` פשוטים, בלי ראוטר.

## מבנה קוד

- `js/storage.js` — כל הגישה ל-`localStorage` (צליל, רמת קושי, שיא, פרופיל שחקן). זה המקום היחיד שקורא/כותב למפתחות האלה, וגם `board.js` וגם `settings.js` משתמשים בו כדי לשמור על עקביות בין המסכים.
- `js/board.js` — מנוע המשחק ורינדור הלוח: בניית הרצף, ניגון הרצף עם תזמון לפי רמת קושי, קליטת הקשות השחקן/ית, עדכון שלב/ניקוד וסיום משחק.
- `js/sound.js` — טוני Web Audio לכל פד ולשגיאה, בהתאם להגדרת הצליל.
- `js/profile.js` — מודל בחירת אווטאר ושם; נפתח בכפייה כשאין פרופיל שמור, ונפתח מחדש (עם אפשרות סגירה) מהאייקון בלוח.
- `js/rules.js` — מודל הסבר חוקי הניקוד, נפתח מאייקון ה-"?" הקבוע לצד אייקון טבלת התוצאות.
- `js/settings.js` — לוגיקת מסך ההגדרות.
- `js/leaderboard.js` — מיזוג נתוני הפלייסהולדר עם שורת השחקן/ית האמיתית ומיון לפי ניקוד.
- `css/styles.css` — כל העיצוב, משותף לשלושת המסכים. הגופן בכל האפליקציה הוא Rubik (נטען מ-Google Fonts).
